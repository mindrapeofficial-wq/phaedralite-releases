# Phaedra Lite releases

This public repository hosts official Phaedra Lite installers and portable archives. The desktop application checks its published GitHub Releases when it starts.

Only published stable releases are offered automatically. Drafts and pre-releases are not offered. Each release includes SHA-256 checksums. The Phaedra Lite source repository is maintained separately.

[View downloads](https://github.com/mindrapeofficial-wq/phaedralite-releases/releases)
